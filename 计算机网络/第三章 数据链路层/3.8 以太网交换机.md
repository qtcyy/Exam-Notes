## 3.8 以太网交换机

> **以太网交换机**：工作在数据链路层，用端口连接多个主机或网段。交换机通过自学习建立交换表，根据 MAC 地址决定帧从哪个端口转发。

### 🧠 回忆录

| 知识点 | 核心内容 | 一句话 |
|------|---------|--------|
| 全双工通信 | 收发可同时进行 | 现代交换式以太网的重要特点 |
| 交换表 | 记录 MAC 地址与端口号的绑定关系 | 交换机转发帧的依据 |
| 自学习 | 根据帧的**源 MAC 地址**建立或更新表项 | 看到谁从哪个端口来，就记下来 |
| 未知目的地址 | 交换表中查不到目的 MAC 时广播/泛洪 | 不知道往哪发，就向其他端口扩散 |
| 表项有效期 | 表项过期后自动作废 | 防止主机移动或拔线后旧记录失效 |
| 直通交换 | 只读帧开头的 6B 目的 MAC 地址就转发 | 时延低，但不支持协议转换 |
| 存储转发交换 | 收完整帧后再转发 | 时延高，但适合差错检测、速率匹配、协议转换 |

---

### 一、交换机的基本特点

- 以太网交换机通常支持**全双工通信**，端口可以同时发送和接收数据。
- 交换机不靠共享总线广播所有数据，而是根据交换表选择转发端口。
- 交换机转发的是 [[第三章 数据链路层/3.6 局域网#六、MAC 帧格式（DIX Ethernet V2）|DIX Ethernet V2 MAC 帧]]。

#### DIX Ethernet V2 帧格式回忆

口诀：**6 6 2 N 4，收发协数验**

```
| 目的地址 6B | 源地址 6B | 类型 2B | 数据 N | FCS 4B |
     收            发        协       数      验
```

其中，交换机转发时最关心：

| 字段 | 用途 |
|------|------|
| **源 MAC 地址** | 用来自学习：记录该 MAC 地址来自哪个端口 |
| **目的 MAC 地址** | 用来查交换表：决定帧应该转发到哪个端口 |

---

### 二、自学习功能

交换机内部维护一张**交换表**：

| MAC 地址 | 端口号 | 有效期 |
|---------|-------|--------|
| 主机的 MAC 地址 | 该主机所在端口 | 到期后自动作废 |

#### 自学习与转发过程

1. 交换机从某个端口收到一帧。
2. 读取该帧的**源 MAC 地址**，把“源 MAC 地址 ↔ 入端口”写入交换表。
3. 读取该帧的**目的 MAC 地址**，在交换表中查找：
   - 若能查到目的 MAC 对应的端口，则把帧转发到该端口；
   - 若查不到目的 MAC，则向其他端口广播/泛洪该帧。
4. 每个表项设置有效期，过期后自动作废，避免主机移动或断开后旧表项长期存在。

> 注意：**自学习看源 MAC，转发查目的 MAC**。如果交换表中没有目的 MAC，才需要广播/泛洪。

---

### 三、两种交换方式

#### 直通交换

直通交换类似“内部线路接通”：交换机不必等待整帧到达，只要读到帧开头的 **6B 目的 MAC 地址**，就可以决定转发端口。

| 特点 | 说明 |
|------|------|
| 读取内容少 | 只读取帧开头的目的 MAC 地址 |
| 时延低 | 不需要等待整帧接收完毕 |
| 不支持协议转换 | 没有完整处理整帧 |
| 差错检测能力弱 | 未完整接收帧，不能先完成 FCS 检查再转发 |

#### 存储转发交换

存储转发交换会先把整个帧接收下来，再检查并决定如何转发。

| 特点 | 说明 |
|------|------|
| 时延较高 | 必须等待整帧到达 |
| 支持差错检测 | 可先检查 FCS，再决定是否转发 |
| 支持速率匹配 | 适合连接不同速率的线路 |
| 支持协议转换 | 例如标准以太网帧转换为带 [[第三章 数据链路层/3.6 局域网#十、VLAN 虚拟局域网|802.1Q VLAN]] 标签的帧 |

---

### 四、直通交换与存储转发对比

| 对比维度 | 直通交换 | 存储转发交换 |
|------|------|------|
| 接收范围 | 只接收帧开头的目的 MAC 地址 | 接收完整帧 |
| 转发时延 | **低** | **高** |
| 差错检测 | 弱，无法先完整检查 FCS | 强，可检查完整帧 |
| 速率匹配 | 不适合 | 适合 |
| 协议转换 | **不支持** | **支持** |

---

### ⚠️ 易错点

1. **交换机自学习的是源 MAC 地址**，不是目的 MAC 地址；目的 MAC 地址用于查表转发。
2. 交换表中查不到时，应理解为**查不到目的 MAC 地址**，因此需要广播/泛洪。
3. **直通交换只读前 6B**，因为 DIX Ethernet V2 帧最前面的 6B 就是目的 MAC 地址。
4. **存储转发交换时延更高**，但能支持差错检测、速率匹配和协议转换。
5. 交换表项要设置有效期，否则主机断开、移动或端口变化后，旧表项会误导后续转发。
